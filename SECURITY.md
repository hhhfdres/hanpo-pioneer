# Security Policy

## Supported versions

The `main` branch receives security fixes. Tagged prototype releases are not supported after a newer minor release.

## Reporting

Do not publish an exploitable issue before a fix is available. Send a private report through the repository's GitHub Security Advisory page with:

- affected component and version,
- reproduction steps,
- expected and actual behavior,
- impact on heating, power, alerting, or personal data,
- suggested mitigation if known.

## Safety boundary

This repository is not certified for life-support or medical use. Security work covers unauthorized actuation, malicious telemetry, replay attacks, location privacy, denial of rescue messaging, and update integrity. Product certification, electrical safety, and clinical performance remain separate obligations.
