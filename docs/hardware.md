## 双重过热保护

软件阈值不能作为唯一安全层。推荐链路为：

```text
NTC -> STM32 ADC -> PWM duty 0
NTC -> 独立比较器 -> MOS 驱动使能拉低
NTC -> 热熔断器或温度开关 -> 总电源切断
```

硬件比较器的动作点应低于软件闭锁点或与其形成冗余。`PB1` 仅用于阅读安全链状态，不能被配置为可关闭该保护。

## PWM 与功率

说明书给出总功率 25 W 和 65 摄氏度闭锁目标。三区功率必须通过实际发热片阻值、MOS 结温、线束压降和热像仪测试重新标定。`config.zone_power_w` 只是软件上限映射，不替代占空比与平均功率的电气测量。

建议：

- 每路配置独立电流采样和自恢复保险丝。
- PWM 驱动级与 MCU 使用隔离或受保护栅极网络。
- 继电器断开后保留传感器和通信供电。
- 表面温度探头直接贴合发热片最热点，不使用仅有环境热惯性的替代测点。

## 能源接口

BQ76940 适合电池组监控场景，柔性超级电容需要一个独立的高边电流采样与均衡边界。若超级电容电压范围为 0 至 3 V，应通过升压或直接低压母线设计明确每个负载的输入范围。

低温预热逻辑在环境温度低于 -30 摄氏度时先进入 2 W、5 分钟预热窗口。该逻辑只控制功率预算，实际预热拓扑、热隔离和温升必须由硬件验证。

## 定位与天线

UM220-III N 与 RDSS 模组需要清晰天空视图。应把天线布置在背部上方，与 BQ76940 和 PWM 功率环路保持距离。RDSS 发射时峰值电流较大，电源去耦和地回流必须在整机状态下验证。
