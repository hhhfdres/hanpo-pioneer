| --- | --- | --- | --- |

| 30 秒重发 | `AlertManager` | 每设备独立发送间隔与确认门控 | 北斗序号和链路回执 |

| 多目标优先级 | `rescue_priority` | 告警、体温、能源、静止时长 | 指挥规则和数据校准 |
| 远程监控 | Dashboard、HTTP API | 实时状态、趋势、事件流和工况注入 | TLS、鉴权、持久化和告警值班 |

## 对说明书指标的处理

说明书中的材料拉伸率、电导率、比电容、定位精度和实验成功率是项目背景与硬件目标，不应被解释为此软件仓库的测试结论。软件测试验证的是状态机、数值边界、接口行为和参考算法是否按预期执行。硬件指标需由对应实验报告、校准证书和独立复测支撑。
