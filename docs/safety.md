# 安全设计说明

## 危险与缓解

| 危险 | 触发条件 | 软件缓解 | 硬件缓解 |
| --- | --- | --- | --- |
| 低温烫伤 | 发热片长时间高占空比 | 65 摄氏度闭锁，55 摄氏度恢复 | 独立比较器、温度开关、熔断器 |
| MCU 失控 | 死循环、时钟异常 | 看门狗，输出默认关闭 | 硬件使能线、比较器 |
| 单路 MOS 短路 | 驱动故障 | 电流与温度趋势监控 | 每路保险丝、总继电器 |
| 错误 SOS | 姿态和温度误判 | 双条件判定、时间窗口 | 人工取消和运营确认 |
| SOS 丢失 | 北斗遮挡或链路拥塞 | 30 秒重发、双链路切换 | 天线布置和功放电源裕量 |
| 电池过放 | 低 SOC 持续供电 | 负载卸载、模式降级 | BQ76940 保护与可更换电池 |
| 模型漂移 | 人群或海况分布变化 | 未知输入回退规则 | 运营审核与版本回滚 |

## 默认安全方向

- 启动、复位和故障时加热输出必须为关闭。
- 过热闭锁只能由低于恢复阈值的温度解除。
- 任何单个传感器异常都不能提高最大功率上限。
- 昏迷模式提高功率，但仍受硬件温度保护。
- 救援确认不应直接覆盖本地低温保护。
- 日志和遥测不得包含不必要的个人身份信息。

## 必须开展的验证

1. 三区 PWM 与总使能失效模式、共因故障和短路测试。
2. 温度传感器断线、短路和漂移测试。
3. 低温启动、浸水、盐雾、振动和跌落后的控制一致性。
4. 北斗遮挡、发射峰值电流和长时间重连测试。
5. 昏迷误触发与漏触发在目标人群上的独立验证。
6. 网络攻击、报文重放、位置伪造和固件更新完整性测试。
